# assets/projects/

Screenshots and images for your project cards live here.

Example (inside a project card in `index.html`):

```html
<img src="assets/projects/ai-interview-agent.png"
     alt="AI Interview Agent — home screen"
     loading="lazy" width="800" height="500">
```

Name files in lowercase with hyphens, e.g. `attendance-system.png`.
