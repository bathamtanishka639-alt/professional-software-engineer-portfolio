# assets/certificates/

Drop your certificate images in this folder, then point a card at the file.

Example (uncomment and edit inside `index.html`):

```html
<img src="assets/certificates/your-certificate.jpg"
     alt="Certificate name — issuing organisation"
     loading="lazy">
```

Recommended: export images at roughly 1200 px wide, JPG or PNG,
landscape orientation, under 300 KB each.

Do not add certificates you have not earned, and never invent a
credential ID — leave the placeholder text as it is until you have it.
